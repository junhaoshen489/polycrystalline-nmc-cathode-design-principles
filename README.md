# 多晶 NMC 正极材料设计原理

## 综述题目

**多晶 NMC 正极的分级颗粒形貌设计：锂离子传输与晶间应变的协同调控**

## 核心研究问题

在成分与表面化学尽可能可比的前提下，如何设计多晶 NMC 的一次颗粒与二次颗粒形貌，使锂离子传输路径、晶间应变释放和电解液润湿达到更优平衡，从而改善倍率、循环寿命与结构完整性？

## 研究边界

- 聚焦多晶 NMC 的一次颗粒尺寸、形状、晶体取向、接触方式，以及二次颗粒尺寸、致密度、孔隙和径向/随机结构。
- 单晶材料仅作为理解边界效应的参照。
- 优先采用能区分形貌变量与化学变量的实验研究；理论计算只作机制补充。
- 未伴随形貌调控的掺杂、包覆和电解液优化不作为主线。

## 综述大纲

1. **为什么“分级形貌”是多晶 NMC 的关键变量？**  界定一次颗粒、孔隙和晶界共存时，传输、反应与力学损伤的共同发生空间。
2. **形貌语言与评价指标：从“颗粒大小”转向可比较的结构描述。**  建立一次颗粒尺寸/长径比/取向分布、二次颗粒尺寸/孔隙率/曲折度，以及裂纹与阻抗的对应表征框架。
3. **一次颗粒形貌：局域扩散距离与各向异性应变如何被改变？**  讨论粒径、片状/等轴形貌、晶粒取向及晶粒接触对脱嵌锂均匀性与晶间开裂起始的影响。
4. **二次颗粒架构：致密、疏松、孔隙梯度与径向结构的代价和收益。**  比较电解液可达性、离子输运曲折度、比表面积、应力释放与副反应之间的权衡。
5. **耦合设计：用“传输—应变”而非单一指标评价形貌。**  将倍率、阻抗增长、裂纹形态和容量保持置于同一因果链中，识别形貌优化的有效窗口。
6. **可迁移的设计原则与实验验证路线。**  提出变量控制、单颗粒/多尺度表征和全电池验证的最低证据要求，并给出后续研究空白。

3. 按设计问题而非逐篇论文组织正文。
